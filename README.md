  - Frontend:

      - `hooks` - contains the custom hooks;

      - `pages` - this module contains the general components for CRUD: 
        - `CRUD` folder, which includes `ChangePassword`, `Users` folders; 
        - `auth` folder;
        - `dashboard` folder;
        - `error` folder;
        - `starter` folder.

      - `routes` - consists of all routes of the application;

      - `services` - consists different services such as socket, data fetching and etc.;

      - `store` - that is, where all our states are stored, it's also contains `reducers` and `actions` folders;

      - `styles` - contains all .scss files of your application;

      - `types` - contains `filter`, `redux` and `formik` folders, where are Typescript types and interfaces;

      - `utils` - Utility functions;

## Running the project locally with Docker

1. Ensure you have the necessary dependencies:
    a. you're running on MacOS with [homebrew](https://brew.sh) already installed
    b. docker - `brew install docker`
    c. MySQL CLI - `brew install mysql-client@8.0`
    d. The `db_abaschedulesv2_3` example .sql file (if sent as a zip file, you'll need to unzip it)
    e. an example .env file, one for `frontend/.env`, one for `backend/.env`
2. Start docker: `docker compose up`
3. Create the MySQL database
    a. run `mysql -u root -h localhost --port 3307 -pmy_secret_password --protocol TCP`, which gives you a MySQL CLI
    b. run `CREATE DATABASE abaschedules;`
    c. exit (`exit`)
4. Load the example database:
    a. `mysql -u root -h localhost --port 3307 -pmy_secret_password --protocol TCP --database abaschedules < PATH_TO_SQL_FILE.sql`
5. Now you can run the front end by cd'ing into frontend/ and running `yarn start`

### Running Tests

1. Before running the tests, copy `backend/.env.test.example` to `backend/.env.test`, and add any missing, secure values.

2. Then run `docker compose run backend yarn test`. 

### Issue with 'Invalid ELF Header'

If you've previously been running the app locally with something other than the version in the docker file, you may end up with a bcrypt "invalid ELF header". 

Delete your `node_modules` folder and run docker-compose up again so that the correct versions get installed, it should work then. 

### Working

Now you're good to go:

- Access phpymyadmin at localhost:8081 (username root, password my_secret_password unless you changed it)
- Access the backend at localhost:8080
- Access the front end localhost:3000
- All the logs will be in your `docker compose up` output.
